# 瓜王争霸

**让水果落下，让合成连起来。**

瓜王争霸是一款竖屏水果合成抖音小游戏。玩家控制落点，让相同等级的水果接触并合成为更高等级，在不断堆高的场地中追求分数、连击和关卡目标。

项目使用原生 JavaScript 与 Canvas，直接对接抖音小游戏 `tt` API。除了基础合成，还加入特殊球、局内天赋、主动技能和局外成长，围绕同一个掉落动作形成不同玩法节奏。

## 核心玩法

1. 点击屏幕控制水果落点。
2. 两个同级水果接触后合并，产生更高级水果与分数。
3. 连续合成积累连击，配合特殊球和技能整理场面。
4. 根据当前状态选择天赋，在有限空间内继续冲关或冲分。
5. 水果堆越过危险线并持续一定时间后结束本局，结算金币和成长进度。

## 双模式与局内变化

### 经典闯关

达到目标分数进入下一关，关卡配置逐步改变目标、掉落池和危险线。通关插页在关卡之间提供过渡，避免状态瞬间跳转。

### 限时狂热

在 60 秒内尽可能冲高分数，与经典模式分别记录最高成绩。

### 特殊球

- **炸弹**：延时爆炸，清理局部区域。
- **冰封**：暂时冻结场上水果，解冻后重新形成碰撞与连锁。
- **双倍**：为后续若干次合成提供分数加成。
- **磁吸**：将水果向中心聚拢，制造新的合成机会。

局内天赋以三选一形式出现，改变连击、分数、技能或危险线容错等参数；主动技能通过合成积累的能量使用。

## 成长与收集

- 金币结算与永久升级，将局外成长叠加到下一局。
- 水果图鉴、成就、称号和玩家统计，记录解锁与挑战经历。
- 每日任务、周任务、挑战与签到等局外目标。
- 金币商店、技能升级和主题皮肤，提供不同阶段的资源选择。
- 静音、震动、减少动效、高对比等设置，以及本地存档导入导出。

金币商店使用游戏内资源；平台广告和分享能力通过相应模块接入，实际可用性取决于开发者配置与平台权限。

## 技术实现

- **圆形物理与合成**：掉落、接触、碰撞修正、合并与特殊状态集中在物理模块。
- **数据驱动**：水果等级、关卡曲线、天赋、成长与主题分开组织，方便调参。
- **逻辑与绘制拆分**：主逻辑组织状态和结算，UI 模块分别绘制 HUD、全屏页面和不同面板。
- **输入分发**：触摸按当前界面层级路由，避免不同页面同时响应一次操作。
- **本地持久化**：最高分、成长、偏好与收集记录通过平台存储保存，并提供存档版本迁移。
- **平台集成**：包含分享封面、录屏分享、侧边栏、桌面入口与好友排行的相关适配。

## 运行

1. 安装并登录抖音开发者工具。
2. 导入本仓库根目录，按自己的账号配置 `project.config.json` 中的 AppID。
3. 编译后在模拟器中体验；真机预览按工具流程操作。

源码中的现有 AppID 不应直接作为其他项目的发布配置。好友关系链、云存储、广告及部分增长接口需要相应权限和真机环境；工程中存在接口适配不代表已通过平台审核。

## 自动化检查

使用 Node.js，不需要额外安装运行依赖：

```sh
node tests/bot-test.js
node tests/soak-test.js
node tests/audit-play.js
```

这些检查使用模拟的 `tt` 与 Canvas 环境，覆盖玩法规则、界面状态、输入操作、渲染调用和随机运行流程；它们不能替代抖音真机测试。
